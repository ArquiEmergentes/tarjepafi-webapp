# TarjePAFI · Web App

Aplicación web de **TarjePAFI** (PafiSolutions): Smart Campus con credenciales NFC y lectores IoT para la UPC, sede San Miguel.

El código está en [`webapp/`](webapp/). Su [README](webapp/README.md) explica la instalación, los usuarios demo, la arquitectura DDD y la tabla de trazabilidad del Sprint 1.

```bash
cd webapp
npm install
npm run dev
```

- Aplicación: http://localhost:4200
- API simulada: http://localhost:3000/api/v1
